# Cloud Automation MCP

云测试报告自动化项目

## 项目结构

```
cloud-automation-mcp/
├── mcp/                # 主流程编排模块
├── skill_sdk_doc/      # SDK文档处理
├── skill_price/        # 价格相关功能
├── skill_buy/          # 购买流程功能
├── skill_test/         # 测试相关功能
├── skill_info/         # 信息查询功能
├── skill_analyze/      # 分析功能
├── skill_report/       # 报告生成功能
├── main.py             # 项目入口
└── README.md           # 项目说明文档
```
